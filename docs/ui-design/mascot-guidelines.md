# FlowProxy 吉祥物规范

## 定位

吉祥物是 C · Warm Flow 主题的品牌视觉角色。它增强亲和力，但不替代真实状态、错误提示或操作按钮。

## V1 造型方向

- 蓝白色圆润科技伙伴。
- 深蓝色面部显示区域，简洁明亮的眼睛/表情。
- 适量橙色与蓝色流动元素。
- 轮廓清晰，缩小后仍可识别。
- 与 A 主题的 Network Orb 形成互补：Orb 表达网络能量，吉祥物表达陪伴感。

## 状态表现

可设计 connected / disconnected / connecting / error 四类静态或轻量状态图。
不得仅通过表情传达错误；错误必须有可读文本和可访问的状态标识。

## 资产交付

正式开发时建议提供：
- SVG 或透明 PNG 主图
- 1x/2x/3x 资源
- 深浅背景预览
- 必要的状态变体
- 资产许可和来源记录

不要把参考图中截图裁切出来的低分辨率吉祥物直接当成最终生产资源；应重新制作可独立使用的品牌资产。
