# C 主题：Warm Flow（可切换）

## 1. 视觉关键词

暖白、柔和蓝、橙色点缀、轻拟物、圆润卡片、亲和、轻松。

## 2. 色彩 tokens（初始建议值）

- `bg.canvas`: `#F4F1F0`
- `bg.sidebar`: `#F8F6F5`
- `surface.primary`: `#FFFFFF`
- `surface.soft`: `#F0E9E5`
- `accent.blue`: `#2897F4`
- `accent.orange`: `#FF9B45`
- `status.connected`: `#18C98B`
- `status.warning`: `#F3A43B`
- `status.error`: `#E85D70`
- `text.primary`: `#283044`
- `text.secondary`: `#7C8495`
- `border.subtle`: `rgba(70,90,130,0.10)`

## 3. 吉祥物

- 首页主视觉使用蓝白色、圆润、友好的小型机器人/猫系科技伙伴。
- 保留参考图中的蓝色主体、深蓝面部显示区、橙色/蓝色环绕元素。
- 吉祥物作为品牌视觉资产，不承担状态判断逻辑。
- 状态必须同时以文字、图标或数值表达，不能只改变吉祥物表情。
- 第一版优先静态高质量插画或少量状态切换，不要先做复杂 3D 实时渲染。

## 4. 卡片和数据

- 使用暖白卡片、柔和阴影和浅色分区。
- 橙色用于强调、流量统计标题或操作反馈。
- 蓝色用于流量曲线、交互和主要数据。
- 地图使用浅色风格，降低视觉噪声。
- 保持与 A 主题相同的信息顺序、组件语义和交互行为。

## 5. 动效

- 轻微浮动、柔和过渡和状态反馈。
- 默认动效比 A 更轻。
- 后台、隐藏窗口和低功耗模式下暂停。
- 支持减少动态效果设置。
